# Steam Library Manager

A Python/Flask app to manage your Steam library with ease. Automatically detects installed and uninstalled games, shows cover art, provides Steam Store links, and allows you to install or uninstall games directly from the app. Includes features for filtering, skipping games, and manually adding games by Steam AppID.

> **Note:** This project was made with AI.

---

## Features

- Detects installed and uninstalled games from your Steam library.
- Shows game cover art and hours played.
- Provides direct links to the Steam Store for each game.
- Install/uninstall games directly from the app.
- Filter games by installed/uninstalled/all.
- Skip games and reset skipped list.
- Manually add games by Steam AppID with automatic info retrieval.
- Clean dark-themed UI (Flask web interface).
- First-run GUI to input Steam API Key, SteamID64, and Steam library folder.
- Automatic browser launch to the app after start.
